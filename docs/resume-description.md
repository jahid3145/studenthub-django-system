# StudentHub — Resume Description & Bullet Points

## Project Title
**StudentHub — Full-Stack Student Management & Academic Administration System**

## One-Line Summary
A modular Django & DRF web application providing academic administration, role-based dashboards, automated grading, attendance tracking, and REST APIs for educational institutions.

---

## 3–5 High-Impact Resume Bullet Points

- **Full-Stack Development**: Engineered a scalable Academic Administration platform using **Python, Django 5, DRF, PostgreSQL, and Bootstrap 5**, supporting 4 distinct user roles (Super Admin, Staff, Teacher, Student).
- **REST API Architecture & JWT Security**: Architected robust RESTful API endpoints utilizing **SimpleJWT** for token-based stateless authentication, implementing custom permission classes to isolate student records.
- **Automated Business Logic**: Built automated engines for attendance warning alerts (`< 75%`), letter grade/GPA calculations, and payment status synchronization in Django ORM.
- **Query Optimization**: Optimized ORM queries using `select_related` and `prefetch_related`, mitigating N+1 query bottlenecks and improving data retrieval speeds.
- **Automated Testing & API Documentation**: Integrated comprehensive unit testing suite across views, models, and REST endpoints, along with OpenAPI/Swagger interactive documentation via DRF Spectacular.

---

## Tech Stack
**Backend**: Python, Django, Django REST Framework, SimpleJWT, django-filter, drf-spectacular  
**Frontend**: HTML5, CSS3, Bootstrap 5, JavaScript (Fetch API), FontAwesome  
**Database**: PostgreSQL, SQLite (local dev)  
**DevOps & Tools**: Git, Postman, Swagger UI
